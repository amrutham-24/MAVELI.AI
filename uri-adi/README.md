# 🌾 MĀYĀLI — Uri Adi Challenge 🏺

An interactive 3D WebXR / VR game celebrating the traditional Onam **Uri Adi** pot-breaking festival challenge.

## Features
- 🥽 **WebVR / WebXR Ready**: Immersive VR headset controls (Quest 3, WebXR compatible).
- 🖱️ **Desktop & Mobile Interactive**: Touch/click screen swing mechanics with raycasting.
- 🎨 **Traditional Aesthetic**: Palette themed after Kasavu gold, terracotta, banana leaf green, and marigold orange with central Pookalam artwork.
- 🔊 **Web Audio Synthesizer**: Procedural ceramic smash and swing sound effects.
- ⚙️ **Configurable Difficulty**: Easy, medium, and hard modes via URL parameters (`?difficulty=hard&player=blue`).
