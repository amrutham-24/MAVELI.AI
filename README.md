# MAVELI.AI
**MAVELI.AI — The Living Onam Game**

MAVELI.AI is an adaptive physical-AI game platform that fuses traditional board game mechanics with dynamic spatial computing and mechatronics. Built around the mythology of Onam, four players navigate an interactive, addressable LED board where live player positions, red snake zones, and green ladder pathways update in real time based on physical and virtual events.

Physical gameplay bridges directly into mixed reality via the Meta Quest 3. Landing on a snake cell initiates an immersive spatial escape trial where real-time physical performance dictates survival. Landing on a ladder triggers an Onam-themed interactive trivia challenge, requiring correct responses to authorize the upward climb. An embedded mechatronic engine—driven by an Arduino microcontroller and high-torque servo actuators—physically updates the board state, controlling structural shifts, indicator mechanisms, and the iconic endgame trapdoor that returns King Mahabali to Pathalam upon final cell victory.

At the core of MAVELI.AI is a real-time player competence model running continuous telemetry on response latency, movement precision, and trivia accuracy. The adaptive AI dynamic balance engine constantly recalculates game parameters—altering spatial time limits, dynamic obstacle speed, and question difficulty per player—to maintain optimal engagement across varying skill levels. MAVELI.AI delivers a closed-loop phygital environment where human input, AI inference, and hardware actuation continuously reshape both physical and virtual realities.
